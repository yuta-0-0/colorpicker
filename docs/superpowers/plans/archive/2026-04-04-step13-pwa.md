### Task 1: PWA アイコンを canvas API で生成し public/ に配置する

**作成ファイル:** `scripts/generate-icons.mjs`（一度だけ実行する Node.js スクリプト）

```javascript
// Node.js 環境で canvas を使ってアイコンを生成する
// 実行: node scripts/generate-icons.mjs

import { createCanvas } from 'canvas'
import { writeFileSync, mkdirSync } from 'fs'
import { resolve, dirname } from 'path'
import { fileURLToPath } from 'url'

const __dirname = dirname(fileURLToPath(import.meta.url))

function generateIcon(size) {
  const canvas = createCanvas(size, size)
  const ctx = canvas.getContext('2d')

  // 背景
  ctx.fillStyle = '#1a1a1a'
  ctx.fillRect(0, 0, size, size)

  // カラーサークル（3色の丸）
  const radius = size * 0.18
  const centers = [
    { x: size * 0.38, y: size * 0.35, color: '#FF6B6B' },
    { x: size * 0.62, y: size * 0.35, color: '#4ECDC4' },
    { x: size * 0.50, y: size * 0.58, color: '#45B7D1' },
  ]

  for (const { x, y, color } of centers) {
    ctx.beginPath()
    ctx.arc(x, y, radius, 0, Math.PI * 2)
    ctx.fillStyle = color
    ctx.fill()
  }

  return canvas.toBuffer('image/png')
}

const publicDir = resolve(__dirname, '../public')
mkdirSync(publicDir, { recursive: true })
writeFileSync(resolve(publicDir, 'icon-192.png'), generateIcon(192))
writeFileSync(resolve(publicDir, 'icon-512.png'), generateIcon(512))
console.log('Icons generated successfully.')
```

**代替案（canvas パッケージなしで済む場合）：**
`canvas` npm パッケージは native addon のため環境によってビルドが重い。代替として：
1. Figma や Sketch で 192x192 / 512x512 の PNG を手動で作成して `public/` に配置する
2. オンラインツール（Favicon.io 等）でアイコンを生成して配置する

どちらの場合も `public/icon-192.png` と `public/icon-512.png` として配置すればよい。

### Task 5: safe-area-inset 対応（iPhone ノッチ・ホームバー）

**変更ファイル:** `src/index.css`（または Tailwind の `@layer base` セクション）

```css
/* iPhone ノッチ・ホームバー対応 */
:root {
  --safe-area-top: env(safe-area-inset-top);
  --safe-area-bottom: env(safe-area-inset-bottom);
  --safe-area-left: env(safe-area-inset-left);
  --safe-area-right: env(safe-area-inset-right);
}

/* スクロール可能なメインコンテンツのホームバー余白 */
.pb-safe {
  padding-bottom: env(safe-area-inset-bottom);
}

.pt-safe {
  padding-top: env(safe-area-inset-top);
}
```

**変更ファイル:** `index.html` の `<meta name="viewport">` タグを更新

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
```

`viewport-fit=cover` が iPhone のノッチ領域まで表示を拡張するために必要。
